# Data Analysis System

Desktop application built with Python for loading, analyzing, and visualizing data from Excel files. Features an interactive GUI that displays data summaries, key statistics, and dynamic charts based on the loaded dataset.

## Features

- Load any Excel file (.xlsx / .xls) with a single click
- Display data in an interactive table (up to 50 rows preview)
- Automatic summary with key statistics per numeric column:
  - Total, Average, Max, Min
- Generate dynamic charts:
  - Bar Chart
  - Line Chart
  - Pie Chart
- Column selector to choose which data to visualize

## Technologies

- Python 3
- Tkinter — Graphical User Interface
- Pandas — Data loading and analysis
- Matplotlib — Chart generation
- OpenPyXL — Excel file reading

## How to Run

1. Clone the repository:
```bash
   git clone https://github.com/keybm24/Data_Analysis_System.git
```
2. Install dependencies:
```bash
   pip install pandas matplotlib openpyxl
```
3. Run the application:
```bash
   python main.py
```
